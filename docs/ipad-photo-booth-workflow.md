# Run an iPad Photo Booth Workflow from Capture to Delivery

This guide helps commercial operators prepare and test an iPad Photo Booth workflow in ChackTok. Compatibility and available controls can vary by iPad model, camera, printer, app version, connection method, and event environment.

## Workflow at a Glance

1. Define the guest experience and promised deliverables.
2. Prepare the iPad, booth, camera, lighting, printer, and network plan.
3. Create or reuse an event template.
4. Configure capture, branding, sharing, and consent settings.
5. Run a complete test session.
6. Operate the guest flow from welcome screen to delivery.
7. Review media, sharing activity, and event data after the booking.

## Choose the Capture Setup

ChackTok can support different capture configurations where compatible:

| Capture setup | When it fits | What to verify |
| --- | --- | --- |
| Built-in iPad camera | Portable, self-service, and compact events | iPad model, mount, camera permission, orientation, lighting |
| DSLR camera | Events that require a professional camera workflow | Camera compatibility, connection method, power, transfer time |
| Mainstream action camera | Motion-led or compact camera workflows | Camera model, firmware, cable or wireless mode, battery, storage |

Use the simplest configuration that can deliver the result promised to the client. Test the exact hardware combination before a paid event.

## Prepare the Event

Before guests arrive:

- Confirm the iPad fits the booth mount and remains powered.
- Test the selected camera, lighting, display, and printer where used.
- Create or clone an event template.
- Add approved logos, frames, overlays, stickers, filters, music, and sharing copy.
- Configure QR code, email, SMS, gallery, and social sharing options where available.
- Configure any disclaimer, consent wording, or guest data collection required by the booking.
- Prepare a backup network and a fallback delivery method.

## Run the Guest Session

Keep the guest sequence short and repeatable:

1. Show the welcome or instruction screen.
2. Let the guest select the available capture option.
3. Capture the photo, video, GIF, or other configured media.
4. Allow preview or retake where the event workflow permits it.
5. Apply the approved visual treatment.
6. Present the configured delivery choices.
7. Reset the booth for the next guest.

For high-volume events, reduce optional steps and prioritize the fastest delivery method.

## Process and Brand the Output

Depending on the selected workflow and app version, ChackTok can support:

- AI background removal and replacement.
- Slow-motion processing and high-frame-rate composition.
- Beauty filters, stickers, frames, overlays, and branded graphics.
- Reusable event templates and batch media management.

Approve templates and client assets before event day. A complete test should confirm that the final output is readable, correctly oriented, and consistent with the client's brand.

## Deliver the Media

Delivery options can include QR code, email, SMS, gallery access, social sharing, and printing where supported.

Venue connectivity should be tested in advance. Offline task queuing can hold eligible upload work until connectivity returns, but operators should still prepare a fallback delivery method and verify the queue after the network is restored.

For printing workflows, test the printer, connection method, paper, consumables, color output, and reprint process before the booking starts.

## Reporting and Consent

Where enabled, ChackTok can support basic event data such as guest email capture, social sharing statistics, and engagement analysis.

Only collect the data required for the booking. Configure guest-facing consent and disclaimer wording before the event, follow applicable privacy rules, and agree with the client on what the post-event report will contain.

## Event Profile Examples

| Booking type | Suggested operating profile | Main risk to control |
| --- | --- | --- |
| Drop-off rental | Built-in iPad camera, short self-service flow, digital delivery | Instructions must work without an attendant |
| Wedding | Branded template, tested lighting, optional printing | Print supplies and venue lighting |
| Corporate activation | Approved graphics, optional external camera/display, reporting setup | Brand approval and consent |
| High-volume event | Minimal capture steps, QR-first delivery, offline queue available | Queue flow and network capacity |

## Final Dry Run

Complete one full session using the actual event configuration:

- Start from the guest welcome screen.
- Capture one item with the selected camera.
- Confirm processing and branding.
- Complete one digital delivery.
- Complete one print if printing is included.
- Disconnect and restore the network to verify the fallback plan.
- Confirm that the booth resets correctly for the next guest.
